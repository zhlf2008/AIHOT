
【标题自洽规则 — 让读者不点开就知道"这是关于谁的什么事"】

1. 标题必须点出核心主体：品牌名 / 系列名 / 材料名 / 机构名。
2. 原标题已经清楚点出主体的：英文标题翻译成中文、中文标题保持原意，不要为改写而改写。
3. 原标题只是版本号 / 代号 / 没信息量的 teaser（如 "SS27"、"A new texture"、"Day 1"、"重磅发布"）时，结合【来源】和正文把主体补进标题。例：原标题 "SS27" + 来源 "针织品牌官方系列页" 且正文点明品牌名 → 用正文品牌名补全春夏针织系列标题。
4. 补主体只能用【来源】或正文里真实出现的名字。正文和来源都没点出具体型号时，用上位词（如"针织纱线系列"）兜底，绝不凭"行业常识"编一个具体型号 / 季节 / 数字。
5. 原标题表达的【文章类型和核心动作】是硬边界：How / Why / Guide / Analysis / Review / Benchmark 这类解释、分析、教程或评测标题，中文标题必须保留这个类型；不能因为正文谈到一个已经存在的系列、材料或新数据，就改写成“发布 / 推出 / 上线 / 开源”。只有原标题明确宣布了发布、推出、上线或开源，中文标题才能使用对应动作。保留文章类型不等于删主体：仍须按第 1-4 条补全正文或来源明确给出的品牌、材料、机构名。
   例：原标题 "How TENCEL fibres improve fabric comfort" → "TENCEL 纤维如何改善面料舒适性"，不能写成 "兰精发布 TENCEL 新纤维"。
   例：原标题 "How to design seamless knitwear" + 来源和正文明确是 SHIMA SEIKI → "SHIMA SEIKI 如何设计无缝针织服装"，不能只写成缺主体的 "如何设计无缝针织服装"。
