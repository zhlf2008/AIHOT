# 使用规则

版本与生效日期：2026-10-16。本站名称：针织时尚 HOT。

本站汇集公开的针织服装趋势与产业资讯，通过模型生成中文标题、短摘要及行业判断，提供匿名阅读、RSS 和只读接口。

## 内容与来源

本站关注秀场趋势、纱线色彩、针织结构与工艺、品牌市场，以及有证据支持的可持续材料信息。摘要、标签、评分和事件归组可能存在错误，重要信息请核对原文。评分是本站的编辑判断，不代表权威机构认证。

原文版权归来源方所有。默认只展示短摘要和原文链接，不转载受限或付费全文；来源明确允许展示全文时，才按其许可范围提供。原文素材的权利不因本站代码采用 MIT 许可而改变。

## 接口使用

网页、RSS、公开 API 与 MCP 的公开内容均可匿名读取。请按响应中的缓存时间更新，遇到 429 时遵守 Retry-After。禁止通过接口获取后台凭据或管理数据。

## 更正与下架

如发现错误、重复、失效链接，或来源方希望调整展示方式，请通过 [GitHub Issues](https://github.com/zhlf2008/AIHOT/issues) 提交对应页面与说明。请勿在公开反馈中填写账号密码或 API Key。

## 预览版本

完整版正在分阶段适配 Cloudflare 与 Supabase。当前阶段仅对已通过验证的功能开放预览，自动采集、成刊和管理功能的上线状态以项目说明为准。本站不保证资讯覆盖完整、摘要始终准确或服务持续可用。
